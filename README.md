# PP BASE MUJOCO
 - The repository is currently under development.
 - If you have any question or suggestion for the code, Feel free to contact


### mujoco_basics
- Basic MuJoCo codes including:
    - Robot spawn
    - Custom GL Viewer
    - Simple torque control with UR5e

### inverse_kinematics
- Simple Forward & Inverse Kinematics examples, including:
    - MuJoCo Jacobian
        - Jacobian pseudo-inverse with SVD (Singular Value Decomposition) & DLS (Damped Least Squares)
    - IK with End-Effector position target
    - IK with both position & orientation target

https://github.com/user-attachments/assets/eee15071-c544-4fcb-a2e2-82b96f67e79b

### inverse_dynamics
- Simple Torque control examples, including:
    - Bias forces (Mass matrix, Gravity, Coriolis)
    - Joint position following with PD Control
    - Push with desired force, PI Control
    - Integrated Controller

### multi_robot_mjspec
- Simple mjSpec examples for multi-robot, including:
    - Simple mjSpec example
    - mjSpec Helper Class

https://github.com/user-attachments/assets/3353dfd9-1ae7-444f-960f-47654cd5aa08
