## Basic codes & projects!
- simple_mujoco_spawn: spawn UR5e robot & control with simple array, multiple glfw windows to render
- practice_mj_spec: utilize mjSpec to spawn multiple robots & modify scene
- practice_ik: practice inverse kinematics, from analytically solving jacobian pseudo-inverse to position control
- proj_rrt_control (project): control robot with joint space rrt path planning
- simple_rl_policy: simple RL controller for robot
